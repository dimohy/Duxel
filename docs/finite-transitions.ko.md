# 유한 값 전환과 탭 스크롤 모션

## 목적과 재사용

기존 `AnimateFloat(string, ...)`, 공통 곡선, UI 시계와 `RequestFrameAt`를 유지한다. 새 소유형 `UiFloatTransition`은 위젯이 수명을 관리하는 값 전환이다. 사라진 위젯의 트랙이 전역 ID 사전에 누적되지 않는다. 두 API가 같은 `UiAnimationCurve`를 사용하며 새 소비자는 유한 프레임 예약을 사용한다.

## 계약

- `new UiFloatTransition(0)`으로 초기 값을 지정하고 `ui.AnimateFloat(ref transition, target, options)`로 샘플한다.
- 매개변수는 시간·목표·곡선·길이·프레임 간격·감소 모션이다. 순수 타임라인의 `Update`는 현재 값·진행 여부·다음 절대 시각을 반환한다.
- 목표가 바뀌면 현재 시점의 값을 새 시작 값으로 사용한다. 나타남 중 숨김이나 숨김 중 재등장이 연속적으로 연결된다.
- 다음 예약은 `min(종료 시각, 현재 시각 + 간격)`이다. 종료·정적 목표·감소 모션에는 예약이 없다. 새 Timer·백그라운드 스레드를 만들지 않는다.
- 유한 수, 지원 곡선, 단조 UI 시계를 검증한다. 다른 컨텍스트의 시계를 사용할 때는 `Reset`한다.
- 기존 문자열 키 API의 수명·연속 플래그 계약은 이번 변경으로 바꾸지 않는다. 새 소유형 API는 별도 연속 애니메이션 플래그 없이 기존 기한 예약을 사용한다.

## 상단 탭 적용

탭 드래그·휠은 실제 헤더를 이동한다. 왼쪽/오른쪽에 가려진 탭이 있을 때 해당 `…`이 나타난다. `…` 클릭은 이동하지 않고 해당 방향의 탭 컨텍스트 메뉴를 연다. 항목을 고르면 원래 선택 바인딩과 본문을 갱신하고 헤더를 노출한다.

하단 3px thumb는 배치를 차지하지 않는 오버레이다. 기본120ms 나타남·400ms 정지 대기·160ms 사라짐이며 길이와 곡선은 `UiTabListScrollOptions.Motion`의 `Enter`·`Exit`에서 설정한다. 드래그 중에는 계속 표시하며 움직임 없이 머무는 동안 주기 렌더링을 요청하지 않는다. 줄어든 콘텐츠·숨김/컨텍스트 이동은 기존 소유 수명에서 취소한다. `ReducedMotion`은 즉시 전환한다.

## 검증 범위

순수 타임라인, 재지정의 연속성, 감소 모션, 정확한 종료, 공통 UI 예약, 드래그 후 클릭 억제, 양끝/중간 표시, 좌우 메뉴, 원래 본문 연결, 작은 뷰포트, 키보드와 RTL을 CPU/GPU에서 검증한다. 실제 NativeAOT·물리 스크린리더·모든 Fluent 적합성은 별도로 검증한다.
