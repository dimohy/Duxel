# 공통 텍스트 드래그 소유권

한 줄·다중 행 편집은 UiState 내부의 텍스트 드래그 소유자 하나와 확인 프레임·double 시각을 공유합니다. 보이고 활성화된 편집 영역에서 누르면 소유권을 얻습니다. 키보드 포커스와 버튼 눌림만으로 시작하지 않습니다. 해제·버튼 올라감·새 누름·동시 누름/해제·활성 컨트롤 변경·소유자 누락·완전 클립·비활성·레이아웃 차단·상위 팝업 차단·컨텍스트 이전·위젯 해제는 소유권을 끝냅니다. 스크롤바에서 누른 입력은 스크롤바가 소유하며 텍스트 드래그로 바뀌지 않습니다.

소유한 다중 행 선택은 영역 밖에서도 기준점을 유지하며 기존 스크롤 경로로 사용 가능한 각 축을 이동합니다. 소유한 드래그가 이어지는 동안만 키보드 커서 자동 노출을 억제합니다. 읽기 전용도 바인딩을 바꾸지 않고 선택합니다. 공유 시각을 사용하므로 이전 입력별 `##dragAutoScrollTime` 스크롤 항목에 기록하지 않으며 해제 시 기존 보조 항목 정리는 유지합니다. 다중 행의 기존 히트 좌표·스크롤 속도·gutter 기하는 유지합니다. 이번 소유권 수정으로 단어/행 드래그·부분 가림·네이티브 창 간 캡처·셰이핑/bidi 전체 동작이 완료된 것은 아닙니다.

고정 .NET 11 RC3에서 초기 소유권14실패를 재현했습니다. 실제 누름·포커스만 있는 입력·해제·클립/팝업/비활성·스크롤바·읽기 전용·양축·컨텍스트/해제 수명의 신규51검사를 포함한 통합 편집 CPU444 통과입니다. 기본·자동 줄바꿈·Fluent 비줄바꿈 구성이며 포커스 대역은 focused/active ID를 모두 설정합니다. 다중 행 GPU는 포커스만 있는 held 입력과 실제 영역 밖 좌우 드래그를 구분하는 96비교를 추가해 2,560검사를 통과했습니다. 명시한 선택·커서를 래스터/벡터·Light/Dark·MSAA1/4·획득 이미지 재사용4회에서 비교합니다. 입력400·Fluent입력1362·접근성40·수명101·컨테이너237·할당경로2317도 통과했습니다.

기존 이미지 지문과 실제 Textarea 샘플 실행은 `artifacts/text-drag-ownership-2026-11-11/verification.json`에 기록합니다. 샘플은 누름·드래그·해제를 안내하고 값·읽기 전용·너비·줄바꿈 전환을 자동 실행하며 OS 포인터를 주입하지 않습니다. 런타임 설정·공개 API를 바꾸지 않았고 통합 성능 개선을 실측하지 않았습니다. 현재 Native/런타임 비교에는 [Native 상태](native-toolchain-status.ko.md)에 기록한 C++/Windows SDK 위치 확인이 필요합니다. 전체 목표 완료 수와 리사이즈 보류는 유지합니다.
