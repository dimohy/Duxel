# Multiline source-element integrity

[Shared text drag ownership](text-drag-ownership.md): single-line and multiline now share explicit press ownership and a timestamp; focus-only held input cannot select. CPU444/multiline2560 pass, including context/scrollbar lifetime and pointer GPU checks. Full OS capture/word-drag/partial-occlusion/native fidelity remains open.

Plain standard multiline editing now uses the edit buffer's lazy .NET `StringInfo` boundaries for movement, deletion, directional selection alignment and nearest-element pointer hits. The existing nonwrapping geometry stays in place. Wrapped/readonly/Fluent editors reuse their owned visual map's source boundaries. The plain path does not create a visual map solely to obtain source boundaries; added boundary-cache cost has not been measured as an allocation or performance improvement.

All paths align before mutation/clipboard/navigation, after queued IME insertion, around held-key mutation, before character input and after each inserted character. This protects an element newly formed with an existing suffix in the same frame. For example, inserting `a` and then `b` before a leading combining mark yields `ábZ`. Partial selections expand to complete elements while retaining direction. Plain vertical targets snap to a complete element; its existing UTF-16-column navigation does not establish pixel-column, shaped or bidi movement fidelity.

Fixed .NET 11 RC3 validation reproduced 21 source failures. The combined editing suite passes 393 checks, including 57 new checks across plain/wrapped/Fluent nonwrapping inputs. Multiline GPU passes 2,464 checks with 128 new actual-key/character comparisons across raster/vector, Light/Dark, MSAA1/4 and four acquired-image reuses. Literal text/caret references cover combining movement, supplementary deletion and same-frame joining. The selected emoji font is explicit and fingerprinted. Prior input693 and multiline3,457 images match. See `artifacts/multiline-elements-2026-11-11/verification.json`.

The Textarea sample includes combining text in its state transitions. Fixture setup failures and the initial nullable warning are preserved, then corrected with the actual Arrange and non-null IME contracts; final build warnings/errors are zero. These managed checks do not prove actual OS IME, external UIA, full Unicode word/line breaking, shaping/bidi/ligatures, official appearance, current Native/runtime comparison or integrated performance. See [Native toolchain status](native-toolchain-status.md) for the recovered historical path and current limitation.
