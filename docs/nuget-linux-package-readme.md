# Duxel.Linux.App

Run a Duxel app on a Linux desktop using X11 and Vulkan. This package provides the `DuxelLinuxApp` host for .NET 8, 9, and 10. For the interactive Gallery and its runnable C# examples, use [Duxel.Gallery.Linux](https://www.nuget.org/packages/Duxel.Gallery.Linux).
