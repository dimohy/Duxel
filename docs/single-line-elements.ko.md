# 한 줄 편집의 원문 텍스트 요소

[한 줄 드래그](input-drag.ko.md): 입력에서 누른 드래그는 영역 밖 선택·가로 자동 스크롤을 이어가고 해제·숨김·클립/비활성·상위 팝업 차단 시 종료합니다. CPU336·입력커널400 통과, 이전 입력357장·다중 행3457장 일치. 실제 OS 캡처와 전체 텍스트/Native 일치는 미완료입니다.

[공통 키보드 명령](text-commands.ko.md): Ctrl+Backspace/Delete와 반복은 온전한 단어 범위를 삭제하고 다중 행 Left/Right는 선택을 접습니다. CPU301·입력커널304·다중행2336 통과이며 전체 네이티브/Unicode/OS 일치는 미완료입니다.

공통 한 줄 커널은 .NET `StringInfo` 텍스트 요소 경계에서 이동·삭제합니다. 보충 문자·결합 문자·연결 이모지를 나누지 않습니다. 요소 내부의 커서 인덱스는 앞 경계로 맞춥니다. 선택 양끝은 방향을 유지하며 온전한 요소로 확장하고 일반 Left/Right는 선택을 앞/뒤 끝으로 접습니다. 요소 내부의 포인터 위치는 측정한 앞/뒤 경계 중 가까운 쪽을 선택합니다.

편집 버퍼가 원문 경계를 지연 캐시하고 Sync/Replace 때 무효화합니다. CR이 없는 ASCII는 경계 배열 없이 인덱스 계산을 사용하며 끝 위치만 사용하는 작업은 캐시 생성을 피할 수 있습니다. 캐시 소유권은 기존 편집 버퍼를 따릅니다. 구현 경로 설명이며 실측 무할당·전앱 성능 개선 주장은 아닙니다.

키보드·누른 키 반복·클립보드·읽기 전용 선택이 같은 경계를 사용합니다. 한 프레임의 편집 사이에도 정렬하여 기존 뒷부분과 새로 결합한 요소를 보호합니다. 단어 이동은 Unicode BMP 문자/숫자·결합 기호를 인식하고 결과를 원문 요소에 맞춥니다. 단어 구분은 언어별/UAX29가 아닌 휴리스틱을 유지합니다. 논리적 원문 이동이 시각적 bidi 이동·셰이핑·합자·실제 OS IME 동작을 입증하지는 않습니다.

고정 .NET 11 RC3에서 초기 CPU 20실패와 추가 선택 접기 2실패를 재현했습니다. 한 줄 새 27개를 포함한 통합 편집 CPU231 통과입니다. 입력 커널 240검사는 기존 144개와 실제 키 이벤트·명시적 표시 문자열·선택 사각형·커서 기준의 새 GPU96비교를 합칩니다. 래스터/벡터·Light/Dark·MSAA1/4·획득 이미지 재사용 4회입니다. 이전 입력 이미지117장과 다중 행 이미지3,265장은 모두 일치합니다. 상세 근거: `artifacts/single-line-elements-2026-11-11/verification.json`.

벡터 검사 첫 실행은 선택 글꼴에 U+1F600이 없어 거부됐습니다. 새 검사에서 설치된 Segoe UI Emoji를 보조 regular 글꼴로 명시하고 글꼴 지문을 기록했습니다. 지원하지 않는 글꼴 오류는 유지합니다. private 반복 헬퍼를 사용하는 연결된 기존 참조의 호출도 호환 오버로드로 보존했습니다. 비교 조건을 낮추지 않았습니다.

`fluent_input_elements_fba.cs`는 편집 가능/읽기 전용 Unicode·호출자 값 교체·명시적 이모지 글꼴을 보여 줍니다. 전체 Unicode/브라우저/글꼴 일치·외부 Windows UIA·실제 OS 입력·현재 Native/런타임 비교·통합 성능은 미완료입니다.
