`UiImmediateContext.RequestFrameAt(double)` and `UiControlContext.RequestFrameAt(double)` declare an absolute deadline in the UI clock returned by `GetTime()` / `TimeSeconds`. Call during rendering. They create no timers, callbacks or background tasks. Non-finite or negative times are rejected; multiple callers share the earliest deadline.

The current frame owns declarations. A subsequent frame replaces them; removing a widget stops future declarations. Context disposal clears the pending deadline. External frame requests, input, resize and exit interrupt the existing event wait. A due deadline produces a frame. Active text input also keeps its independent caret blink.

For example, `ui.RequestFrameAt(ui.GetTime() + 0.25)` requests a later refresh while allowing the app to wait. Repeat only when the rendered state still requires it. A time at or before the current UI time requests immediate work.

Fluent Spinner uses this path during its visible delay. Visible motion still requests continuous animation. Generated widgets and direct/custom implementations use the same engine.

Retained static/versioned layers remember and republish their earliest deadline. Due layers rebuild. Continuous-animation layers rebuild until their children stop requesting motion; unrelated static layers remain reusable. These scheduling dependencies do not retain input/accessibility semantics for a manually cached drawing body. Offscreen animation culling remains separate work.

Bounded visual animation now uses `UiControlContext.RequestAnimation(UiRect bounds)`. Spinner and Fluent Progress use it with their local paint bounds. The common engine tests the current clip, nested 2D layer translations and zero-opacity ancestors before waking. It retains the animation dependency, so returning onscreen or restoring opacity resumes motion. The parameterless request intentionally keeps logical/nonvisual work active. Projected scenes remain active unless an ancestor has zero opacity; projected culling is not implemented. A hidden animated layer can still rebuild when other work produces frames, and its initial geometry capture still occurs. This change suppresses unnecessary wakes; it does not finish all CPU/geometry caching work.

Retained replay also composes existing child translation with parent translation and converts the parent clip into command-local coordinates. Previously it replaced child translation. Focused GPU tests compare opposite/summed nested translations, partial clipping and multiplied opacity against direct reference images.
