# Duxel version history

## 0.4.0

- Duxel Gallery for Windows and Linux has platform-specific NuGet launchers and browsable Fluent 2, graphics, layout, and document examples.
- `Fluent.Text` accepts a `Text` style selector. Gallery includes richer image-format and fit examples, a dedicated SizedBox page, and Align examples covering all nine positions.
- Gallery CodeView supports selection and a localized context menu. The menu offers Copy for a selection and Select All for unselected text.
- `Duxel.App`, `Duxel.Windows.App`, and `Duxel.Linux.App` ship .NET 8, 9, and 10 assets. Gallery uses .NET 11.
