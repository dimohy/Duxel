# 둥근 페인트 클리핑

`UiDrawListBuilder.RoundedClip(bounds, radius)`와 `UiControlContext.RoundedClip(bounds, radius)`는 페인트를 둥근 사각형 내부로 제한합니다. 좌표는 그리는 기하와 같은 로컬 좌표입니다. 경계와 반지름은 유한해야 하며 너비·높이·반지름은 음수가 될 수 없습니다. 반지름은 작은 변 길이의 절반까지 제한합니다. 중첩 범위는 역순으로 닫습니다.

```csharp
var paint = new UiControlContext(ui);
using (paint.RoundedClip(new(20, 20, 120, 96), 24))
{
    paint.Frame(new(0, 0, 200, 160), new(255, 0, 0), default, 0, 0);
}
```

중첩 범위는 조상 경계와 교차합니다. 원형 잘라내기와 함께 사용할 수 있습니다. 기존 원형 전용 계산은 마스크 재질 내부에서 유지하며 마스크가 없는 재질은 마스크 레코드를 읽지 않습니다. 기존 부호 거리·미분 기반 커버리지 정책을 MSAA1에서도 사용합니다. 다각형 근사나 샘플 수 강제 증가를 사용하지 않습니다. 기하 할당이나 레이아웃을 바꾸지 않는 페인트 범위이므로 사용자 정의 인터랙티브 위젯은 보이는 영역과 입력 판정을 함께 맞춰야 합니다. 팝업 빌더는 독립된 페인트 범위를 사용합니다.

기존 명령 속성 `CircleCutoutIndexPlusOne`은 둥근 마스크 체인의 시작점도 가리킵니다. 보조 레코드는 기존32바이트 primitive 스트림에서 앞선 레코드를 상대 인덱스로 연결합니다. 전체 목록 복사는 연결을 유지하고 분할 복사는 연결을 다시 만듭니다. 캐시·참조 추가는 외부 경계를 명령의 이동 전 로컬 좌표로 변환하고 사각 클립도 함께 교차합니다. 원본 기하는 바꾸지 않습니다. 마스크 변경은 정적 버전에 반영되며 부분 갱신 스냅샷은 모든 조상의 경계와 반지름을 비교합니다. 조상만 바꿔도 각 획득 이미지가 복구되고, 변화가 없는 프레임은 그리기와 업로드를 생략할 수 있습니다. 클립 내부의 외부 그리기 콜백은 명시적으로 실패합니다.

셰이더는 Vulkan1.2/SPIR-V1.5를 대상으로 하며128바이트 푸시 상수 배치를 유지합니다. shaderInt64나 고정 subgroup 폭을 요구하지 않습니다. 프래그먼트 단계에서 기존 버퍼 주소 기능으로 마스크를 읽습니다. [공식 버퍼 주소 가이드](https://docs.vulkan.org/guide/latest/buffer_device_address.html)를 참고하세요. 단계 간 주소는 정수 성분으로 전달하며 생성한 체인은 항상 앞선 레코드로 연결합니다.

`./run-gallery.ps1` → **렌더링** → **둥근 클리핑 : 꺼짐**을 누릅니다. 정적 도형·3D 투영·캐시된 겹침 캡처의 모서리를 확인하고 원형 잘라내기와 조합할 수 있습니다. 탭 전환 후에도 설정을 유지하며 애니메이션 타이머를 추가하지 않습니다. Card는 사용자 정의 보조 슬롯·0패딩 콘텐츠와 둥근 입력 경계에 이 페인트 범위를 연결합니다. Card Preview는 별도 잔여 작업입니다.
