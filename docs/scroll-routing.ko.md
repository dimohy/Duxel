# 중첩 스크롤 입력 전달

2026-11-10 [소유 ScrollView](scroll-view.ko.md): Dux.ScrollView가 유한 뷰포트 측정·실제 자식 배치·오프셋·스크롤바 수명과 무효화를 소유합니다. CPU47·별도 GPU/좌표1933검사 통과. 월드 좌표 정밀도 부족은 명시적으로 거부하며 큰 콘텐츠 재배치/가상화·현재 Native는 미완료입니다. 컨테이너3/6 유지. 샘플: `layout_scroll_view_fba.cs`.

2026-11-10 변경은 기존 자식 뷰포트와 내부 창의 입력 커널을 정리합니다. 소유권을 가진 새 스크롤 위젯이나 가상화 단계를 완료한 것은 아닙니다.

`EndChild`는 포인터가 있는 가장 안쪽 뷰포트부터 휠을 전달합니다. 범위 안으로 제한한 오프셋이 실제로 바뀔 때만 이벤트를 소비합니다. 요청 방향의 경계에 이미 도달한 안쪽 뷰포트는 바깥 자식이나 내부 창에 이벤트를 남깁니다. 두 축의 소유권은 독립적입니다. 경계까지 일부만 이동해도 이벤트 전체를 소비하며, 남은 소수 휠 이동량의 분배는 구현하지 않았습니다.

휠의 히트 검사는 뷰포트와 호출자 클립의 양수 면적 교집합, 팝업 계층과 현재 내부 창의 순서를 사용합니다. 공통 세로·가로 스크롤바도 최초 손잡이 캡처와 트랙 클릭에 같은 검사를 사용합니다. 위쪽 팝업이나 클립 밖의 트랙은 포인터를 캡처하지 못합니다. 이미 포인터를 소유한 손잡이는 클립 밖에서도 해제까지 드래그를 계속합니다. 팝업 스크롤바는 부모 창 사각형과 독립적으로 자신의 계층을 유지합니다.

내부 창의 휠 이동량은 실제로 측정한 텍스트 줄 높이를 사용합니다. DirectText에서 아틀라스 줄 높이가 실제 글자 메트릭을 제공하지 않는 경우도 포함합니다. 위젯/컨텍스트 필드, 캐시, 대체 렌더 경로는 추가하지 않았습니다. 콘텐츠 배치와 저장 오프셋은 기존 커널을 유지합니다. 기존 자식의 프레임 지연도 유지하며, `EndChild`에서 처리한 휠은 다음 요청 프레임의 오프셋에 반영됩니다.

## 검증

근거: `artifacts/scroll-routing-2026-11-10/verification.json`. 수정 전 자식 전용 13조건 중 경계·클립 7조건이 실패했습니다. 추가 검사는 내부 창의 줄 높이 경로도 수정 전에 드러냈습니다. 최종 고정 .NET11 RC3 빌드는 경고·오류 0개이며 확대 회귀 1,645검사(CPU 1,133, GPU 512)가 통과했습니다. 새 스크롤 범위는 CPU 18검사, GPU 오프셋 32검사와 실제 취득 이미지 일치 32검사입니다. 기존 좌표·말단 검사를 포함하므로 각 범위를 고유 요구사항처럼 합산하지 않습니다.

래스터/벡터, Light/Dark, MSAA 1/4와 프레임 슬롯 3에서 두 축의 이동과 경계 전달을 확인합니다. 이벤트 다음 프레임을 독립적으로 지정한 예상 오프셋의 이미지와 비교합니다. 준비 프레임과 기존 회귀를 포함해 readback은 1,025회입니다. 픽셀 일치를 업로드·CPU 할당·FPS 개선으로 해석하지 않습니다.

`samples/fba/layout_scroll_routing_fba.cs`는 중첩 뷰포트, 입력 클립, 행 수 변경과 클릭 가능한 행을 보여 줍니다. 지원 셸에서는 `./run-fba.ps1 samples/fba/layout_scroll_routing_fba.cs -NoCache`를 우선합니다. 기록된 스모크는 기존 PS5 실행기 한계 때문에 본문이 같은 로컬 프로젝트 사본을 사용했고, 빌드와 15초 종료가 성공했습니다. 시작 확인이며 수동 OS 조작 승인은 아닙니다. 현재 Native/런타임 비교, 외부 Windows UIA와 공식 외형 승인은 미검증입니다. 사용자 리사이즈 보류도 유지합니다.

## 남은 컨테이너 작업

원장은 3/6을 유지합니다. 후속 [UiScrollView 체크포인트](scroll-view.ko.md)가 유한 측정·실제 할당·소유권/해제와 무효화를 제공합니다. 큰 콘텐츠 좌표 재배치와 가상화는 미완료입니다. 기존 목록·콤보·여러 줄 편집기의 휠 처리는 모두 이 도우미로 옮기지 않았습니다. 이들이 공유하는 스크롤바의 히트 검사는 이번 수정에 포함됩니다.
