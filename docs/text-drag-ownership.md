# Shared text drag ownership

Single-line and multiline editing share one internal UiState text-drag owner, seen frame and double timestamp. A visible, enabled editing-area press claims it; keyboard focus and a held button alone do not. Release/up, a new press, coalesced press/release, active-control transfer, an omitted owner, full clipping, disable, layout blocking, higher popup blocking, context transfer and disposal end ownership. A scrollbar press belongs to the scrollbar and cannot become a text drag.

Owned multiline selection continues outside the field and preserves its anchor while the existing scroll paths pan each available axis. Only an owned continuation suppresses keyboard caret reveal. Readonly text remains selectable without binding changes. The shared timestamp replaces writes of the old per-input `##dragAutoScrollTime` scroll entry; teardown retains cleanup of legacy auxiliary entries. Existing multiline hit coordinates, scroll speeds and gutter geometry remain in place. This is an ownership correction, not a claim that word/line drag, partial occlusion, native cross-window capture or shaping/bidi behavior is complete.

Fixed .NET 11 RC3 validation reproduced 14 initial ownership failures. The combined editing suite passes 444 checks, including 51 new plain/wrapped/Fluent hard-line checks for actual presses, focus-only input, release, clip/popup/disable, scrollbars, readonly, both axes and context/disposal lifetime. The focus-only fixture explicitly sets both focused and active IDs. Multiline GPU passes 2,560 checks with 96 added comparisons: focus-only held input versus actual left/right outside drags, literal selection/caret references, raster/vector, Light/Dark, MSAA1/4 and four acquired-image reuses. Input400, FluentInput1362, accessibility40, lifetime101, containers237 and allocation-routing2317 also pass.

The sample describes press/drag/release and automatically exercises value/readonly/width/wrap transitions; it does not inject OS pointer input. No runtime settings or public APIs changed, and no integrated performance gain was measured.
