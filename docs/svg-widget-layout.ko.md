# SVG 위젯 배치

SVG 호의 conic 제어점과 양의 가중치는 최초 컴파일에서 보관합니다. 경계·클립·필터·테두리·점선·CPU 진단과 GPU가 같은 곡선을 사용하며, 확대 시 CPU에서 경로를 다시 펼치지 않습니다. 장면·테두리 셰이더 프로토콜은4입니다. 장면 push constant96바이트와 테두리40바이트는 유지합니다. 저수준 곡선3개 레코드의 구간 표식은0=직선,1=cubic,음수=conic 가중치입니다. 테두리 종류7은 동차 가중치3개를 보존하고 점선 곡선 종류2도 같은 가중치를 보존합니다. 잘못된 종류·구간·가중치는 제출 전에 거부합니다. [정확도와 남은 범위](svg-browser-validation.ko.md).

2026-11-17: `UiSvg.Background`는 SVG를 그리기 **전** GPU 출력 대상에 채우는 색입니다. 기본값은 투명이며, 마지막에 전체 이미지에 곱하는 `Tint`와 구분됩니다. 반투명 색은 premultiplied RGBA8로 저장합니다. 내부 그룹·마스크·패턴·필터는 투명한 작업 대상을 유지합니다. 배경은 텍스처 캐시 키에 포함되며, 같은 배경으로 돌아오면 기존 출력을 재사용합니다. XML이나 벡터 장면을 다시 준비하지 않습니다. 여백·확대·회전·클립의 기존 배치 계약은 유지합니다.

```csharp
using var preview = new UiSvg(store.Load(svgPath))
{
    Background = new UiColor(255, 255, 255)
};
```

갤러리 **추가 샘플 → SVG → 브라우저 비교 → 흰색 배경을 SVG에 포함**에서 투명 텍스처를 나중에 흰색에 합성하는 경우와 직접 비교할 수 있습니다. 이 선택이 모든 문서를 브라우저와 같게 만드는 것은 아닙니다. [검증과 한계](../artifacts/svg-target-background-2026-11-17/verification.json).

2026-11-14 : SVG의 Zoom/RotationDegrees는 이제 공통 UiWidget.Transform에 연결되며 별도의 회전 기하를 유지하지 않습니다. Margin도 공통 속성입니다. [공통 변환·회전 중심·시각 모드](widget-transform-contract.ko.md)를 함께 참고하세요.

`UiSvg`는 회전·확대된 콘텐츠의 축 정렬 경계 크기로 레이아웃에 참여합니다. `Size`는 변환 전의 논리 크기이며0이면 문서 고유 크기를 사용합니다.64×48 문서를90° 회전하면48×64,2배 확대와90° 회전을 함께 적용하면96×128이 됩니다. 다음 가로·세로 항목도 이 경계 뒤에 배치됩니다.

`Margin`은 변환된 콘텐츠 바깥의 왼쪽·위·오른쪽·아래 공간을 확보합니다. 각 값은0 이상이며, XML 처리나 래스터 작업 없이 측정·배치에 반영됩니다. 기존 `Offset`은 호환용 축약으로 유지합니다. 양수 X/Y는 왼쪽/위, 음수는 오른쪽/아래 여백을 선택합니다. 새 코드는 `Margin`의 네 방향을 명시하세요.

```csharp
using var preview = new UiSvg(document)
{
    Size = new(64, 48),
    Zoom = 2,
    RotationDegrees = 90,
    Margin = new(12, 8, 0, 0)
};
// Unconstrained measured size:108×136. The content raster remains128×96.
```

`UiWidgetTransformLayout`이 측정·그리기 정점·래스터 크기에 동일한 변환 경계를 제공합니다.90° 단위 회전은 정확한 값으로 처리해 크기 오차를 막습니다. 회전·여백은 래스터와 텍스처를 재사용하고, 확대는 보관한 장면을 해당 해상도로 그립니다. 부모가 명시적으로 크기를 제한하면 최종 할당에 반영합니다. 변환 전 콘텐츠의 모서리를 둥글게 처리해 회전·확대를 함께 적용하며 부모의 스크롤·클립도 유지합니다.

Implementation Observer의 **SVG → 브라우저 비교**에서 상단 확대·회전·여백·모서리 조절을 사용하세요. 두 Duxel SVG 미리보기에 함께 적용하며 왼쪽 브라우저 캡처는 고정 기준으로 유지합니다. 각 SVG에 변환·여백을 포함한 배치 폭·높이를 표시합니다. **SVG 변환 초기화**로 원래 배치로 돌아옵니다. [실행·비교 안내](svg-browser-validation.ko.md#옵저버에서-확인)를 참조하세요.

부모 제약의 순수 측정, 직각·임의 각도 회전, 네 방향 여백, 다음 가로·세로 항목 배치, 캐시 재사용, MSAA1/4 실제 Vulkan 픽셀과 Observer 조절 경로를 검증합니다. 전체 SVG 문서의 브라우저 픽셀 일치는 별도의 미완료 기준입니다.

전체 위젯의 공통 동작·회전 중심·입력은 [공통 위젯 변환 계약](widget-transform-contract.ko.md)으로 추적합니다. 이 통합은 아직 미완료입니다.
