# 다중 행 원문 요소 무결성

[공통 텍스트 드래그 소유권](text-drag-ownership.ko.md): 한 줄·다중 행이 실제 누름 소유권과 시각을 공유하고 포커스만 있는 held 입력은 선택하지 않습니다. CPU444·다중행2560 통과, 컨텍스트/스크롤바 수명과 포인터 GPU 포함. 실제 OS 캡처·단어 드래그·부분 가림·Native 전체 일치는 미완료입니다.

기본 비줄바꿈 다중 행 편집도 이동·삭제·방향 선택 정렬·가까운 요소 포인터 검사에 편집 버퍼의 지연 .NET `StringInfo` 경계를 사용합니다. 기존 비줄바꿈 기하는 유지합니다. 자동 줄바꿈·읽기 전용·Fluent 입력은 소유 시각적 행 지도의 원문 경계를 재사용합니다. 기본 경로에서 원문 경계만 얻기 위해 시각적 행 지도를 만들지는 않으며 경계 캐시의 추가 비용을 할당·성능 개선으로 실측한 것은 아닙니다.

모든 경로는 변경·클립보드·이동 전, 대기 IME 삽입 후, 누른 키 변경 사이, 문자 입력 전과 문자별 삽입 후에 정렬합니다. 같은 프레임에서 기존 뒷부분과 새로 결합한 요소를 보호합니다. 예를 들어 선행 결합 기호 앞에 `a`, `b`를 차례로 넣으면 `ábZ`가 됩니다. 부분 선택은 방향을 유지하며 온전한 요소로 확장합니다. 기본 세로 이동도 온전한 요소로 맞추지만 기존 UTF-16 열 기준 이동을 유지하므로 픽셀 열·셰이핑·bidi 이동 일치를 입증하지는 않습니다.

고정 .NET 11 RC3에서 원문 처리 21실패를 재현했습니다. 기본·자동 줄바꿈·Fluent 비줄바꿈 신규57검사를 포함한 통합 편집 CPU393 통과입니다. 다중 행 GPU는 실제 키·문자 입력128비교를 추가한 2,464검사를 통과했습니다. 래스터/벡터·Light/Dark·MSAA1/4·획득 이미지 재사용4회에서 명시한 텍스트·커서로 결합 문자 이동·보충 문자 삭제·동일 프레임 결합을 확인합니다. 이모지 글꼴은 명시적으로 선택하고 지문을 기록했습니다. 이전 입력693장·다중 행3,457장은 모두 일치합니다. 근거: `artifacts/multiline-elements-2026-11-11/verification.json`.

Textarea 샘플의 값 전환에도 결합 문자를 넣었습니다. 새 대역의 초기 Arrange 누락과 nullable 경고는 보존하고 실제 Arrange·null을 받지 않는 IME 계약에 맞춰 교정했습니다. 최종 빌드는 경고·오류0입니다. 관리형 검사는 실제 OS IME·외부 UIA·전체 Unicode 단어/줄 구분·셰이핑/bidi/합자·공식 외형·현재 Native/런타임 비교·통합 성능을 입증하지 않습니다. [Native 도구 상태](native-toolchain-status.ko.md)에 이전 성공 경로와 현재 제약을 기록했습니다.
