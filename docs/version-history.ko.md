# Duxel 버전 이력

## 0.4.0

- Windows와 Linux에서 운영체제별 NuGet 패키지로 Duxel Gallery를 실행합니다. Fluent 2 컨트롤, 그래픽, 레이아웃, 문서 예제를 바로 써 볼 수 있습니다.
- `Fluent.Text`의 `Text` 값으로 글꼴 스타일을 선택합니다. Gallery에 이미지 형식과 맞춤 비교, SizedBox 전용 페이지, Align의 아홉 가지 위치 예제를 추가했습니다.
- Gallery CodeView에서 코드를 선택하고 오른쪽 버튼 메뉴를 열 수 있습니다. 선택 영역이 있으면 복사, 없으면 전체 선택을 표시합니다.
- `Duxel.App`, `Duxel.Windows.App`, `Duxel.Linux.App`은 .NET 8·9·10용 자산을 제공합니다. Gallery는 .NET 11을 사용합니다.
