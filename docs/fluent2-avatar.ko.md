# Fluent Avatar

[English](fluent2-avatar.md)

## 한글 이름과 상태 원 보정

`Fluent.Avatar("정세일")`은 `Initials = null`일 때 **정**을 표시합니다. 분해된 한글 자모도 첫 글자 단위로 조합합니다. 기존 Fluent 원본 규칙의 한글 자동 추출 제외를 한국어 사용 요구에 맞춰 확장했습니다. 이름 정리는 속성 변경 때만 실행하며 프레임마다 반복하지 않습니다. 명시한 `Initials`는 여전히 우선하고 빈 문자열은 아이콘 모드입니다. 이미지를 지정하면 이미지가 우선합니다.

관찰 샘플의 **아바타 한글 이니셜**도 하드코딩한 글자 대신 이름에서 추출합니다. `./run-gallery.ps1` → **아바타** → **아바타 이니셜** → 이름을 `정세일`로 입력하세요. 상태 배지 전환과 크기·좌우 방향도 함께 확인할 수 있습니다.

상태 원이 오른쪽에서 잘리던 문제는 폰트 비트맵의 음수 가로 원점이 누락되어 생겼습니다. `PlatformTextLayoutResult.OriginX`와 `PlatformTextRasterizeResult.OriginX`를 캐시까지 보존하고 아이콘 위치에 적용합니다. 레이아웃·래스터 원점도 일치해야 합니다. 아바타·부모의 클립을 풀거나 임의로 배지 크기를 줄이지 않습니다. 벡터 경로와 일반 글자 배치는 기존 계약을 유지합니다.

검증: CPU55개/8402회, GPU12개 프로필/2289회(Avatar688·Presence552), 네이티브 Avatar23·Card14. 원의 가장자리 검사48회와 한글 자동/명시 그리기 비교8회를 포함합니다. 근거: `artifacts/avatar-korean-presence-2026-11-12/verification.json`. 전체 목표·고정 RC3 배포 검증은 미완료입니다.

## 비활성 외관

`avatar.Options = avatar.Options with { IsInactive = true };`로 전환합니다. 본체와 상태 배지 전체를 최종0.875배 해상도로 캡처하고 가운데0.875배로 배치한 뒤 불투명도0.8을 한 번 적용합니다. 활동 링·그림자 옵션은 보존하되 숨기며, 자연 측정에서 장식 범위를 제외하고 기본 접근성 이름에서도 활동 문구를 제외합니다. `IsInactive=false`로 복원하면 선택한 장식을 다시 표시합니다. 실제 부모 할당은 레이아웃과 단일 UIA Image의 영역으로 유지합니다. 비활성 외관은 위젯을 사용 불가로 만들거나 입력 동작을 추가하지 않습니다.

위젯이 `UiPaintGroup`을 소유합니다. 이미지·이니셜·기본 사람 아이콘이 같으면 다른 이유로 요청한 프레임에서도 캡처를 재사용합니다. 실제 이미지 소스 식별자·내용·옵션·테마 색상·설정된 타이포그래피를 캐시 입력에 포함합니다. SVG 아이콘은 일반 문서 버전을 제공하며 문서 변경은 프레임도 요청합니다. 다른 아이콘 그리기는 `icon.WithContentVersion(version)`으로 버전을 명시하지 않으면 요청된 프레임마다 평가합니다. 외부 그리기 입력이 바뀌면 버전을 바꾸고 새 아이콘을 대입하세요. 사용자 Avatar 프레젠테이션의 `CanRetainPaint` 기본값은 false입니다. 전달한 내용·옵션과 설정된 테마·타이포그래피만 사용하는 순수 그리기일 때만 재사용을 허용하세요. 주기 타이머는 없으며 위젯·컨텍스트 해제와 대기 프레임의 자원 임대 계약을 따릅니다.

`./run-gallery.ps1` 실행 → **아바타** → **아바타 비활성 전환**에서 확인합니다. 이미지·SVG·한글 이니셜·상태 배지·링·그림자도 함께 조작할 수 있습니다. 관리 실행 검증은 CPU54개/8283회·GPU1374회·외부 네이티브 Avatar23회이며 기존 결정론적 이미지635장이 일치합니다. Light/Dark×MSAA1/4 각 조합에서 새로운 비활성 정의28개는 최초 오프스크린 패스56회를 실행하고 불변 재생에서는 캡처 패스를 실행하지 않았습니다. 이는 캡처 재사용 근거이며 지연·메모리 감소나 원래 RC3 NativeAOT 성능 결과가 아닙니다. 근거: `artifacts/inactive-avatar-2026-11-12/verification.json`. 모션·강제 색상·전체 RTL/Fluent 적합성과 원래 배포·성능 관문은 남아 있습니다.

`Fluent.Avatar`는 사람·그룹을 나타내는 정적 이미지입니다. Fluent 크기14종, 원형·사각, 디코딩된 불변 이미지, 자동·명시적 이니셜과 빌려 쓰는 아이콘을 지원합니다. 입력 동작·탭 포커스·호버 상태·애니메이션 타이머를 등록하지 않습니다.

```csharp
using var avatar = Fluent.Avatar("Ada Lovelace",
    new(UiAvatarSize.Size64, UiAvatarShape.Circular, UiAvatarColor.Colorful));
avatar.Source = imageSource; // 이미 디코딩한 PNG/SVG 픽셀을 가운데 채웁니다.
avatar.Render(ui);
```

이미지가 있으면 먼저 표시하고, 없으면 이니셜, 둘 다 없으면 아이콘을 표시합니다. 기본 사람 아이콘은 기존에 포함된 Fluent 아이콘 폰트를 컴파일된 카탈로그로 그립니다. `Icon = svgIcon.MenuIcon`은 기존 SVG 그리기 객체를 빌립니다. 이를 사용하는 위젯이 해제될 때까지 아이콘 소유자를 유지하세요. 이미지 디코딩 오류를 감추거나 다른 자산으로 바꾸지 않습니다.

`Initials = null`이면 Name에서 이니셜을 구하고, 빈 문자열이면 아이콘을 선택합니다.16px는 자동 이니셜 하나, 나머지는 최대 두 개를 구합니다. 한글 이름은 첫 음절을 자동으로 구합니다. 아랍어·BMP 한중일 문자와 전화번호는 기존 규칙에 따라 자동 이니셜을 제외합니다. `Initials = "김"`처럼 명시하면 자동 추출보다 우선합니다. 접근성 이름은 전체 Name을 유지합니다. 명시적 이니셜은 그대로 표시하며 너무 긴 값은 영역에서 잘립니다. 이름 정리·UTF-16 색상 해시는 속성을 바꿀 때만 계산합니다. RightToLeft는 자동 이니셜의 순서만 바꿉니다.

`UiAvatarColor`는 Neutral·Brand·Colorful과 이름색30종을 지원합니다. Colorful은 `IdForColor ?? Name`에 고정 웹 해시·팔레트를 적용합니다. 글자는 Fluent 세미볼드 규격을 사용합니다. 사각 모서리는 크기<=24/<=48/<=72/그 이상에서2/4/6/8px입니다. 부모가 할당한 사각 영역 안에 정사각형을 가운데 배치합니다. 이미지는 공통 GPU 둥근 뷰포트·Cover UV를 사용하므로 크기·모양을 바꿔도 CPU 리샘플링·원본 디코딩·텍스처 재업로드를 하지 않습니다.

위젯은 내부 이미지 임대를 소유하고 불변 Source와 아이콘 그리기 객체를 빌립니다. Source를 null로 바꾸면 임대를 해제합니다. 같은 컨텍스트에서 Avatar와 Image가 같은 소스 객체를 쓰면 텍스처도 공유합니다. 명시적 유지 레이어의 무효화·자원 수명 계약은 그대로 적용합니다. `UiAvatar<TPresentation>`은 사용자 Measure/Paint를 받습니다. 측정 재사용은 기본적으로 허용하지 않고, 잘못된 크기는 실패시키며, 실제 부모 할당과 클립을 그리기에 전달합니다. Content.Image는 그리기용 참조이므로 프레젠테이션에서 변경·해제하면 안 됩니다.

이름이 있는 Avatar는 네이티브 UIA Image(ControlType50006) 하나를 노출합니다. Invoke·Value·키보드 포커스는 없습니다. 공통 수집기가 커밋된 Name 변경 이벤트를 전달합니다. 표시를 생략하면 이전 공급자를 무효화하고 비활성화·재활성화는 식별자를 유지합니다. 별도 설명이 필요하면 상속된 AccessibleName을 설정하세요.

저장소 루트에서 `./run-gallery.ps1` 실행 후 **아바타**를 선택하세요. 창이 좁으면 더 보기 메뉴를 사용합니다. 이름·모양·크기·색·이미지·SVG 아이콘·한글 이니셜을 바꾸고14개 크기를 비교할 수 있습니다. 탭을 왕복해도 상태를 유지하며 대기 중 주기 프레임을 요청하지 않습니다.

현재 기본 기능 근거는 `artifacts/fluent-avatar-2026-11-12/`입니다. 활동 링과 상태 배지 겹침은 아래에서 설명합니다. 전환 효과·강제 색상·전체 RTL/Fluent·원래 NativeAOT/성능 검증은 남아 있습니다. 팩터리 노출은 웹 Avatar 전체 기능과의 동등성 완료를 뜻하지 않습니다.

## 독립 상태 배지
`Fluent.PresenceBadge`는8개 상태·외근·6개 크기를 지원합니다. `./run-gallery.ps1` 실행→**아바타**→**상태 배지**에서 상태·외근·크기를 바꾸세요. 스크롤되는 페이지는 상태를 유지하며 주기 프레임을 요청하지 않습니다. 기본 아이콘은 컴파일된 Fluent 폰트이고 전달한 SVG painter는 캐시를 재사용합니다. [API·자원 수명·검증](fluent2-presence-badge.ko.md). Avatar 겹침과 활동 링은 아래 계약을 따르며 비활성 외관은 위의 현재 계약을 따릅니다.

## 활동 링과 갤러리 스크롤

`avatar.Options = avatar.Options with { ShowActivityRing = true };`로 활동 링을 켭니다. `avatar.ActivityText = "활동 중";`으로 접근성 문구를 지정할 수 있습니다. 기본 이름에 활동 문구를 더하며 `AccessibleName`을 지정하면 그 값이 우선합니다. 이름은 속성 변경 때 저장합니다. 링을 표시해도 동작·포커스·호버·애니메이션 타이머가 없는 Image 하나입니다.

자연 크기에서는 본체가 선택한14개 크기를 유지합니다. 네이티브 레이아웃은 전체 시각 영역을 측정합니다. 본체48px 이하는 선2px,64px 이하는3px,그보다 크면4px이며 각 방향에 선 두께의2배를 예약합니다(본체32px→전체40px). 장식을 이웃 할당 영역에 덧그리지 않도록 공간을 확보합니다. 부모 영역이 작으면 본체와 간격을 같은 비율로 줄입니다. 원형·사각형과 밝음·어두움의 링 색은 기존 analytic 테두리 전용 primitive와 고정된 persona 팔레트를 재사용합니다. 간격에는 아무것도 칠하지 않아 아래 픽셀을 보존합니다. 크기·링 전환은 기존 이미지 텍스처 임대를 재사용합니다. `ShowActivityRing=false`는 일반 아바타로 돌아가며 Fluent의 비활동 표현 구현을 뜻하지 않습니다.

저장소 루트에서 `./run-gallery.ps1` 실행→**아바타**→**아바타 활동 링**을 누르세요. 샘플은 활동 문구를 한국어로 지정합니다. 페이지는 공통 `UiScrollView`를 사용해 콘텐츠가 창보다 커져도 flex 높이 초과 오류 없이 스크롤됩니다.800×400 창에서 실제 끝까지 스크롤하고 탭 전환 후 위치와 모델을 유지하는지 검사합니다.

현재 근거는 `artifacts/fluent-avatar-ring-2026-11-12/verification.json`이며 SDK11.0.100/runtime11.0.0 관리 실행입니다. 전체 Fluent 활동/비활동 전환·강제 색과 원래 고정 RC3 NativeAOT/전체 부하 검증은 남아 있습니다. [상태 배지](fluent2-presence-badge.ko.md)는 독립 위젯과 아래 Avatar 겹침에서 사용할 수 있으며 이미지·이니셜·아이콘과 링에 공통 투명 마스크를 적용합니다.

## Avatar 상태 배지 겹침

`UiAvatarOptions.Presence`에 `new UiAvatarPresenceOptions(UiPresenceStatus.Available)`를 지정하고 null로 제거합니다. `Size = null`이면 고정한 공식 크기 규칙을 적용합니다. 본체28px 미만→6px,28px 이상→10px,40px 이상→12px,56px 이상→16px,64px 이상→20px,96px 이상→28px입니다. `UiBadgeSize`를 명시하면 그 크기를 사용합니다. 배지는 본체 오른쪽 아래, `RightToLeft`이면 왼쪽 아래에 맞춥니다. 투명 간격은 Medium까지1px,Large/ExtraLarge는2px입니다. 이미지·이니셜·폰트/SVG 아이콘·활동 링에 공통 원형 잘라내기를 적용한 뒤 범위를 종료하고 배지를 그립니다. 배경색으로 빈틈을 덮지 않습니다.

자연 크기는 본체·활동 링·배지의 합집합을 예약합니다. 본체보다 큰 명시 배지도 포함하며 실제 부모 영역 안에 전체를 같은 비율로 맞춥니다. `PresenceText = null`이면 기본 상태 문구를 사용합니다. 한국어 문구를 지정할 때는 필요한 외근 표현까지 포함한 완전한 문구를 전달하세요. 기본 접근성 이름은 사람·상태·활동을 속성 변경 때 합쳐 저장하고 `AccessibleName`이 우선합니다. 상호작용 없는 Image 제공자 하나를 유지하며 배지 자식 제공자·포커스·Invoke·애니메이션 타이머를 추가하지 않습니다. 기존 이미지 임대와 아이콘 소유자 수명 규칙을 유지합니다.

`./run-gallery.ps1` 실행→**아바타**→**아바타 상태 배지**에서 확인하세요. 상태·외근·자동/명시 크기·좌우 전환과 기존 이미지·한글 이니셜·SVG 아이콘·활동 링을 함께 조작할 수 있습니다. 탭을 바꿔도 상태가 유지됩니다. 관리 실행 검증과 한계는 `artifacts/avatar-presence-2026-11-12/`에 기록합니다. 모션/강제 색·Fluent 전체 적합성과 원래 고정 RC3 NativeAOT/성능 관문은 남아 있습니다.

## Avatar 활동 그림자

`ShowActivityShadow = true`는 `ShowActivityRing`과 독립적으로 켭니다. 둘을 함께 켜도 같은 Image 이름에 캐시한 ActivityText를 한 번만 더합니다. 고정한 본체 크기 규칙은28px 이하→Shadow4,48px 이하→Shadow8,64px 이하→Shadow16,그보다 크면Shadow28입니다. 그림자만 켜면 본체 외곽,링도 켜면 전체 링 외곽을 사용합니다. 그림자 범위·링·큰 명시 배지까지 측정하고 실제 부모 영역 안에 같은 비율로 맞춥니다. 고정한 원문의 그림자 가상 요소처럼 그림자를 먼저 그린 뒤 본체/링 잘라내기와 배지를 처리합니다. 이미지·이니셜·폰트/SVG가 같은 경로를 사용합니다.
