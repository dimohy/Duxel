# Windows용 Duxel Gallery

[English](README.md) · [Gallery 사용법](../../docs/gallery-navigation.ko.md)

Fluent 2 컨트롤, 레이아웃, 그래픽 예제를 직접 써 보고 C# 코드를 복사할 수 있습니다. **Fluent 컨트롤 → 동작과 탐색 → MenuBar**에서 상단 메뉴와 키보드 바로가기, 하위 메뉴를 확인합니다.

저장소 루트에서 실행합니다.

~~~powershell
dotnet run --project samples/Duxel.Gallery -f net11.0-windows
~~~

저장소에 지정된 SDK와 Vulkan 드라이버가 필요합니다. 해당 런타임을 설치하면 `net8.0-windows`, `net9.0-windows`, `net10.0-windows`도 선택할 수 있습니다. 공개 패키지로 시작하려면 [Windows 실행 안내](../../README.ko.md#duxel-gallery-040-실행하기)를 참고하세요.
