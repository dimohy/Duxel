# Duxel Gallery for Windows

[한국어](README.ko.md) · [Gallery guide](../../docs/gallery-navigation.md)

Browse Fluent 2 controls, layouts, and graphics. Each interactive example includes C# you can copy. In **Fluent controls → Actions and navigation → MenuBar**, try top-level menus, keyboard access keys, and a submenu.

From the repository root, run:

~~~powershell
dotnet run --project samples/Duxel.Gallery -f net11.0-windows
~~~

Install the SDK pinned by the repository and a Vulkan driver. You can select `net8.0-windows`, `net9.0-windows`, or `net10.0-windows` with the corresponding runtime installed. To start with a published package, see the [Windows quick start](../../README.md#try-duxel-gallery-040).
