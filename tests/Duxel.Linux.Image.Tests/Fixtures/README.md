These small original fixtures exercise straight alpha, odd RGB row widths, two-frame GIF, JPEG, DIB/PNG ICO, multiple ICO directory entries and UTF-8 filenames. They were generated explicitly with Pillow, not during builds/tests. Each .rgba/.size pair is Pillow's independent decoded first-frame expectation; multi-size ICO expectations explicitly select directory entry zero (16x16), rather than Pillow's default largest size. Lossless formats require byte equality; JPEG allows a three-level channel difference between implementations. shapes.svg is an original text-authored rectangle/checkmark scene. invalid.png, truncated.ico and corrupt-frame.ico are deliberately malformed inputs. Native codec errors are test failures, never a reason to replace a fixture or silently switch decoders.
