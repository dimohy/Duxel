# Curved stroke fixtures

`red-body-stroke.svg` and `red-window-stroke.svg` retain the original path geometry and stroke style from [Red Gallardo](https://commons.wikimedia.org/wiki/File:Red_Gallardo.svg), with fill disabled for diagnostic isolation. Source authors: Tomeq183, Tacosunday and Svgalbertian. License: [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/). See the [original corpus attribution](../ATTRIBUTION.md).

The original source SHA-256 and independent browser pixel hashes are recorded in `manifest.json`. Browser results are captured from the isolated source, never generated by the engine under test. The remaining eighteen fixtures are independently authored diagnostic shapes.
