# Viewport fixtures

`red-body-fill-stroke.svg` and `red-window-fill-stroke.svg` isolate two paths of [Red Gallardo](https://commons.wikimedia.org/wiki/File:Red_Gallardo.svg) by hiding the other shapes. Authored geometry and stroke/fill styles remain unchanged. Authors: Tomeq183, Tacosunday and Svgalbertian. License: [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/). See the [original attribution](../ATTRIBUTION.md).

The remaining fourteen inputs are independently authored diagnostic shapes. Native browser bytes and every input are hash-pinned in `manifest.json`.
